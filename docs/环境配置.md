> 适用：Windows 11 + VSCode + Navicat + MySQL 8.0 + GitHub + Python venv。
> 目标：Day 0 把开发环境一次性搭好，后面只专注写代码。

---

## 1. Python 虚拟环境

### 1.1 确认 Python
打开 **PowerShell** 或 **Git Bash**，输入：
```powershell
python --version
# 期望：Python 3.11.x 或 3.13.x
```
若提示找不到 python，去 python.org 安装 3.11+，安装时勾选 "Add to PATH"。

### 1.2 建虚拟环境（在项目根目录）
```powershell
cd D:\fintech-risk-system
python -m venv venv
```
- 会在项目下生成 `venv/` 文件夹（已被 .gitignore 忽略）。

### 1.3 激活虚拟环境
```powershell
venv\Scripts\activate
```
激活后命令行前面会出现 `(venv)` 字样。**以后每次打开终端写代码前都要先激活它。**

### 1.4 升级 pip 并装依赖
```powershell
python -m pip install --upgrade pip
pip install -r requirements.txt
```
- 装包会花几分钟（torch / transformers 较大）。
- 装完验证：`pip list | findstr -i "pandas xgboost transformers streamlit"`

> ⚠️ **把 pip 缓存也挪到 D 盘（防止 C 盘爆）**：pip 默认把下载的包缓存到 `C:\Users\shirley\AppData\Local\pip\Cache`，装 torch 这类大包会塞进去几个 GB。
> 装包前先设环境变量，让缓存走 D 盘：
> **⚠️ 语法提醒：下面是 PowerShell 写法，必须用 `$env:变量名 = "值"`。若直接写 `变量名=值` 会报「无法将…识别为 cmdlet」——那是 bash 语法，PowerShell 不认。Git Bash 用户才用 `export 变量名="值"`。**
> ```powershell
> $env:PIP_CACHE_DIR = "D:\pip_cache"        # PowerShell，仅当前终端有效
> # （Git Bash：export PIP_CACHE_DIR="D:/pip_cache"）
> mkdir D:\pip_cache -Force
> pip install -r requirements.txt
> ```
> 也可永久生效：在「系统环境变量」里新建 `PIP_CACHE_DIR = D:\pip_cache`。这样 C 盘彻底不背这个项目的缓存。

> ⚠️ **Hugging Face 数据集 / 模型缓存也要挪到 D 盘**：`huggingface_hub` 默认把下载的数据集、模型权重缓存在 `C:\Users\shirley\.cache\huggingface`，后面下 AML 数据集、做 LLM 微调都往这塞，会很占 C 盘。
> 装包前同样设环境变量（建议和 PIP_CACHE_DIR 一起设置）：
> ```powershell
> $env:HF_HOME = "D:\hf_cache"          # PowerShell，控制 datasets + models 缓存
> # （Git Bash：export HF_HOME="D:/hf_cache"）
> mkdir D:\hf_cache -Force
> ```
> 永久生效：系统环境变量新建 `HF_HOME = D:\hf_cache`。

> 踩坑：若在 Windows 上装 `torch` 报错，多半是网络问题，可重试；或用清华镜像：
> `pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple`

## 2. 数据库 MySQL 8.0 + Navicat

### 2.1 安装 MySQL
- 下载 MySQL Installer for Windows，选 "Developer Default" 或单独装 "MySQL Server 8.0"。
- 记住你设置的 **root 密码**（后面连 Navicat 要用）。
- 安装完 MySQL 会作为服务后台运行。

### 2.2 Navicat 连接
1. 打开 Navicat → 连接 → MySQL。
2. 连接名：`local_fintech`；主机 `127.0.0.1`；端口 `3306`；用户名 `root`；密码填你设的。
3. 点"测试连接"，成功 → 确定。

### 2.3 建库
- 在连接上右键 → 新建数据库 → 数据库名 `fintech_risk`；字符集 `utf8mb4`；排序规则 `utf8mb4_0900_ai_ci`。
- 或执行 `sql/01_create_db.sql`。

### 2.4 Python 连 MySQL 的密码配置
本项目用 `sqlalchemy + pymysql`。**连接逻辑统一封装在 `src/warehouse/db_utils.py`**，
任何脚本要用库，只写一行导入即可，不要自己拼连接串：

```python
from src.warehouse.db_utils import get_engine
engine = get_engine()
```

密码走环境变量（仅当前终端有效，不落盘）：
```powershell
$env:DB_PASSWORD = "你的root密码"
$env:DB_USER     = "root"          # 可选，默认 root
$env:DB_PASSWORD = "RiskApp#2026"  # 若改用专用账号则同步改 DB_USER
```

**验证连通：**
```powershell
python src/warehouse/db_utils.py
# 成功输出：MySQL connection OK / current db : fintech_risk / SELECT 1 : 1
```

> ⚠️ **坑（已踩过）**：不要手写 `f"mysql+pymysql://root:{pwd}@127.0.0.1:3306/db"`。
> 一旦密码里含 `@ : / # ?`，连接串会在错误位置被切开。例如密码是 `@0124` 时，
> SQLAlchemy 会把主机解析成 `0124@127.0.0.1`，报一个极具误导性的
> `getaddrinfo failed`（看起来像网络问题，其实密码格式炸了）。
> `db_utils.py` 用 `sqlalchemy.engine.URL.create()` 构造连接串，从根上避免这类问题。

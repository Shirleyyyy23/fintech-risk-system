# 运行说明（从 0 到跑通全链路）

> 每个阶段对应实践指南里的 Week。按顺序推进，每完成一步就 git commit。

---

## 0. 首次克隆 / 初始化
```powershell
# 若已从 GitHub 克隆：
git clone <你的仓库地址> fintech-risk-system
cd fintech-risk-system

# 若本地已有（本机已建好骨架）：
cd D:\fintech-risk-system

# 激活环境 + 装依赖
venv\Scripts\activate
pip install -r requirements.txt
```

## 1. 数据采集（W1）
```powershell
python src/ingestion/download_datasets.py
# 下载 HF 两个数据集到 data/raw/，并打印行数/字段校验
```
完成后在 Navicat 里 `source sql/01_create_db.sql` 建库。

## 2. 预处理（W1）
- 跑 `notebooks/02_preprocess_credit.ipynb` 与 `02_preprocess_aml.ipynb`
- 产出 `data/processed/credit_clean.csv`、`aml_clean.csv`

## 3. 数仓 + OLAP（W2）
- `src/warehouse/build_star_schema.py` 建星型模型并导入 MySQL
- `sql/dw_credit.sql`、`sql/dw_aml.sql` 对应 DDL
- `sql/06_olap_queries.sql` 跑 ≥10 条切片查询

## 4. 分析与建模（W2–W3）
- `notebooks/04_*`（描述）、`05_*`（诊断）、`06_*`（预测）、`07_*`（处方/SHAP）、`08_*`（评估）

## 5. 可视化（W3）
- 用 Power BI 打开 `dashboard/credit_risk.pbix` 等
- `src/app/streamlit_app.py`：`streamlit run src/app/streamlit_app.py`

## 6. AI 模块（W4）
- `src/ai/finetune_lora.py`：LoRA 微调中文风控助手
- `src/ai/rag_knowledge.py`：洗钱手法 RAG 问答

## 7. 打包（W4–W5）
- 更新 README 亮点、写 `reports/技术博客.md`、录 `outputs/demo_video.mp4`
- `git add . && git commit -m "chore: finalize project"` 并 push
